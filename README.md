# GPIOZero Examples

The `src` folder contains four example files demonstrating the use of the GPIOZero module:

1. **blink.py**  
    A simple example showing how to blink an LED using GPIOZero's `LED` class.

2. **button.py**  
    Demonstrates how to use a button to control an LED, showcasing GPIOZero's `Button` and `LED` classes.

3. **pwm_pulse.py**  
    Uses a `PWMLED` to control the brightness of an LED.

Each example is designed to be beginner-friendly and highlights specific features of the GPIOZero library.
